# Dana Game APK Releases

Private hosting for **Dana Game APK** files used by [danagameapks.id](https://danagameapks.id).

## How to upload (you do this)

1. Open **Releases** → **Create a new release**
2. Tag example: `v5.2.1`
3. Title example: `Dana Game APK 5.2.1`
4. Attach the `.apk` file (do **not** commit the APK into git)
5. Publish release
6. Copy the asset download URL (ends with `.apk`) and send it in chat

## Rules

- Prefer **GitHub Releases** for binaries (not git commits)
- Keep one clear latest release
- After upload, site `downloadUrl` + SHA-256 will be updated on danagameapks.id
